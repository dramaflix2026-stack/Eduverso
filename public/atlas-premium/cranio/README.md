# Imagens do crânio — Atlas Premium

Coloque nesta pasta exatamente quatro imagens PNG, com estes nomes:

- `frontal.png` — vista frontal
- `lateral.png` — vista lateral
- `posterior.png` — vista posterior
- `inferior.png` — vista inferior

As imagens precisam ser revisadas quanto à precisão anatômica antes da publicação como conteúdo educativo. Esta pasta é exclusiva do Atlas Premium e não modifica o Atlas gratuito.
