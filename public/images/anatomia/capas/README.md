# Capas do Atlas de Anatomia — Eduverso

Esta pasta é usada pelas **6 categorias principais** da Biblioteca de Atlas do Eduverso.

Faça upload dos **6 arquivos WebP**, individualmente, na branch `main`, sem renomeá-los:

| Categoria | Nome exato |
| --- | --- |
| Sistema esquelético | `sistema-esqueletico.webp` |
| Músculos e movimento | `musculos-movimento.webp` |
| Neuroanatomia | `neuroanatomia.webp` |
| Cardiovascular e respiratório | `cardiovascular-respiratorio.webp` |
| Órgãos e sistemas internos | `orgaos-sistemas-internos.webp` |
| Sentidos e outros sistemas | `sentidos-outros-sistemas.webp` |

As imagens são **capas ilustrativas**. Não substituem os diagramas anatômicos interativos ou suas fontes.

Os caminhos públicos correspondentes são `/images/anatomia/capas/<nome>.webp`.

Se uma capa ainda não estiver presente, a interface preservará a arte original de fallback.
