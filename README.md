# Eduverso

Plataforma educacional visual com IA para estudantes e professores.

## MVP
- Biblioteca visual por disciplinas
- Criação de roteiros de estudo, flashcards e avaliações
- Correção comentada e reforço personalizado
- Planos Estudante, Pro e Professor

## Arquitetura
Next.js (frontend e rotas backend), Railway (hospedagem), Supabase (Auth e dados — **não conectado até autorização**).

## Desenvolvimento
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

A geração por IA ainda não está conectada. Nunca coloque chaves de API no navegador ou no Git.
